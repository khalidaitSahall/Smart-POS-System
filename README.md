# 🛒 نظام الكاشير وإدارة المبيعات المتكامل (Smart POS System)

نظام نقاط بيع (Point of Sale) وإدارة مخزون شامل مصمم خصيصاً للمحلات التجارية. يعمل النظام بأسلوب **Offline-First**، ويهدف إلى تسهيل عمليات البيع وإدارة المنتجات والزبائن والموردين مع توفير التقارير اللازمة لإدارة المحل.

## ✨ المميزات الرئيسية

- إدارة عمليات البيع والفواتير.
- البحث عن المنتجات وقراءة الباركود (Barcode Scanner).
- تعليق الفاتورة (Hold Bill) واستكمالها لاحقاً.
- إدارة المرتجعات (Refunds).
- إدارة المنتجات والمخزون والتنبيه عند انخفاض الكمية.
- إدارة الزبائن والديون والموردين والمشتريات.
- إدارة المستخدمين والصلاحيات.
- التقارير والإحصائيات ومتابعة حركة المبيعات.
- إدارة درج النقدية وفتح وإغلاق الوردية.
- العمل دون اتصال بالإنترنت ومزامنة البيانات.
- طباعة الفواتير باستخدام الطابعات الحرارية.

## 🧰 المتطلبات والأجهزة

- جهاز كمبيوتر أو جهاز نقاط بيع بشاشة لمس (Touchscreen POS Terminal).
- طابعة فواتير حرارية (Thermal Receipt Printer) بعرض 80mm أو 58mm.
- قارئ باركود 1D/2D يعمل عبر USB.
- درج نقدية (Cash Drawer).

## 🧱 التقنية المستخدمة (Tech Stack)

- **Frontend:** React.js + Tailwind CSS.
- **Desktop:** Electron.js أو Tauri.
- **Backend:** Node.js (Express / NestJS) أو Python (FastAPI).
- **Database:** SQLite للعمل المحلي، وPostgreSQL للمزامنة أو الاستخدام متعدد الأجهزة.

## 🗄️ تصميم قاعدة البيانات

| اسم الجدول | الحقول الأساسية (Columns) | الوصف |
|---|---|---|
| `users` | `id`, `name`, `username`, `password_hash`, `role`, `created_at` | بيانات المستخدمين والصلاحيات |
| `categories` | `id`, `name`, `description` | تصنيفات المنتجات |
| `products` | `id`, `barcode`, `name`, `category_id`, `cost_price`, `sell_price`, `stock_quantity`, `min_stock_alert`, `expiry_date` | المنتجات والمخزون |
| `customers` | `id`, `name`, `phone`, `total_debt`, `credit_limit` | بيانات الزبائن والديون |
| `suppliers` | `id`, `name`, `company`, `phone`, `balance` | بيانات الموردين والأرصدة |
| `sales` | `id`, `invoice_number`, `user_id`, `customer_id`, `subtotal`, `discount`, `tax`, `total_amount`, `payment_method`, `status`, `created_at` | فواتير وعمليات البيع |
| `sale_items` | `id`, `sale_id`, `product_id`, `quantity`, `unit_price`, `subtotal` | تفاصيل المنتجات في كل عملية بيع |
| `purchases` | `id`, `supplier_id`, `total_amount`, `paid_amount`, `created_at` | مشتريات الموردين |
| `cash_registers` | `id`, `user_id`, `opening_balance`, `closing_balance`, `opened_at`, `closed_at` | تسجيل فتح وإغلاق درج النقدية |

## 🚀 طريقة التثبيت والتشغيل

1. استنساخ المستودع:

   ```bash
   git clone https://github.com/username/smart-pos-system.git
   ```

2. الدخول إلى مجلد المشروع:

   ```bash
   cd smart-pos-system
   ```

3. تثبيت حزم الخلفية (Backend):

   ```bash
   cd backend && npm install
   ```

4. تثبيت حزم الواجهة (Frontend):

   ```bash
   cd ../frontend && npm install
   ```

5. نسخ ملف الإعدادات وتعديله:

   ```bash
   cp .env.example .env
   ```

6. تشغيل النظام في وضع التطوير:

   ```bash
   npm run dev
   ```
