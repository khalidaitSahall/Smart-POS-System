🛒 نظام الكاشير وإدارة المبيعات المتكامل (Smart POS System)نظام نقاط بيع (Point of Sale) وإدارة مخزون شامل مصمم خصيصاً للمحلات التجاريةيجمع بين السرعة في الأداء، سهولة الاستخدام، والقدرة على العمل بدون إنترنت (Offline-First) مع المزامنة السحابية التلقائية.نظرة عامة • الميزات الرئيسية • التقنيات والأجهزة • هيكل المشروع • قاعدة البيانات • التثبيت🎯 نظرة عامة على النظاميهدف هذا المشروع إلى أتمتة جميع العمليات اليومية داخل المحل التجاري، بدءاً من مسح المنتجات بالباركود، إصدار الفواتير الحرارية، إدارة الديون (الكريدي)، وصولاً إلى جرد المخزون واستخراج تقارير الأرباح الدقيقة لصاحب المحل.✨ الميزات والوظائف الرئيسيةالقسمالميزات الأساسية🖥️ نقطة البيع (POS)• دعم كامل لقارئ الباركود (Barcode Scanner) واختصارات لوحة المفاتيح.• إمكانية تعليق الفاتورة (Hold Bill) وإرجاع المنتجات (Refunds).• تعدد طرق الدفع (نقدي، بطاقة بنكية، أو دفع آجل/كريدي).• تطبيق خصومات على مستوى المنتج الواحد أو الفاتورة كاملة.📦 إدارة المخزون• تصنيف المنتجات حسب الفئات، العلامات التجارية، والوحدات (قطعة، علبة، كغ).• تنبيهات ذكية عند وصول المنتج للحد الأدنى أو قرب انتهاء الصلاحية.• توليد وطباعة ملصقات الباركود للمنتجات غير المرقمة.👥 العملاء والموردين• سجل الديون (الكريدي) لتتبع المبالغ المستحقة وإصدار كشوفات حساب.• تسجيل فواتير المشتريات من الموردين وتحديث متوسط التكلفة تلقائياً.📊 التقارير والمالية• إغلاق الصندوق اليومي (Z-Report) ومطابقة النقد الفعلي في الدرج.• حساب صافي الأرباح (سعر البيع - التكلفة - المصاريف).• تقارير المنتجات الأكثر مبيعاً والمنتجات الراكدة.🔐 الأمان والصلاحيات• نظام صلاحيات دقيق (RBAC) لفصل مهام الكاشير عن المدير.• سجل نشاطات (Audit Log) لتتبع كل حركة حساسة داخل النظام.💻 المتطلبات التقنية والأجهزة1. الأجهزة المطلوبة (Hardware)جهاز الحاسوب: حاسوب مكتبي أو شاشة لمس (Touchscreen POS Terminal).طابعة الفواتير: طابعة حرارية (Thermal Receipt Printer) مقاس 80mm أو 58mm.قارئ الباركود: ماسح ضوئي (1D/2D Barcode Scanner) يعمل عبر USB أو لاسلكي.درج النقود: درج إلكتروني (Cash Drawer) متصل بالطابعة الحرارية.طابعة ملصقات: طابعة باركود (اختياري).2. التقنيات البرمجية (Tech Stack)الواجهة الأمامية (Frontend): React.js + Tailwind CSSتطبيق سطح المكتب (Desktop): Electron.js أو Tauri (للتحكم المباشر في الطابعات ودرج النقود).الخادم الخلفي (Backend): Node.js (Express / NestJS) أو Python (FastAPI)قاعدة البيانات (Database): SQLite (للتخزين المحلي السريع بدون إنترنت) + PostgreSQL (للمزامنة السحابية).📂 هيكل المجلدات والملفاتsmart-pos-system/

git clone https://github.com/username/smart-pos-system.git

# 2. الدخول إلى مجلد المشروع
cd smart-pos-system

# 3. تثبيت حزم الخلفية (Backend)
cd backend && npm install

# 4. تثبيت حزم الواجهة (Frontend)
cd ../frontend && npm install

# 5. نسخ ملف الإعدادات وتعديله
cp .env.example .env

# 6. تشغيل النظام في وضع التطوير
npm run dev
